## 👋 About Me

チームリーダー／スクラムマスターとして、開発チームの運営やプロセス改善に取り組んできました。  
エンジニアとしての実務経験を背景に、個人の頑張りに依存せず、  
チームが迷わず判断し、前に進める「仕組みづくり」を重視しています。  
現在は、これまでの経験を活かしてプロダクトマネジメント領域へのキャリアシフトを進めています。
